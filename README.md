# 🏠 RoomieMatch

**Find your ideal roommate and the right place to live.**

RoomieMatch is a mobile application designed to help users find compatible roommates and discover shared accommodation based on their preferences, lifestyle, budget, and preferred city.

## ✨ Features

- **User Authentication:** Login and registration screens.
- **User Profiles:** Manage personal information and lifestyle preferences.
- **Accommodation Discovery:** Browse available shared apartments and studios.
- **Roommate Preferences:** Match preferences such as budget, smoking habits, and pets.
- **City Selection:** Explore accommodation in Paris, Lyon, Marseille, Rabat, Casablanca, Marrakech, Agadir, and Tangier.

## 🛠️ Technologies

- React Native
- Expo
- JavaScript / TypeScript
- Firebase

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Expo development environment
- Expo Go or an appropriate emulator

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Samia-ND/RoomieMatch.git
   ```

2. Navigate to the project directory:

   ```bash
   cd RoomieMatch
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npx expo start
   ```

Follow the Expo terminal instructions to run the app on a device or emulator.

## 🔐 Configuration

If Firebase is required, configure the appropriate Firebase settings for your development environment. Never commit private service-account keys, passwords, access tokens, or other secrets.
